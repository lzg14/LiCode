## 2. P0 — 立即可见的修复

### 2.1 (F01/F02) 装 `@biomejs/biome` + 清理 11 个 `biome-*.txt`

**症状**：

- `package.json` 的 `devDependencies` 不含 `@biomejs/biome`
- 根目录有 `biome-1.txt` ~ `biome-11.txt` 共 11 个临时文件
- 任何新贡献者跑 `bun install && bunx biome` 都失败

**根因**：

- 之前曾尝试加 biome 但未提交到 `package.json`
- `biome.json` 是手工创建的，但 biome 工具本身未列入 devDeps
- 临时文件是某次调试（可能是 `--diagnostic-level`）残留

**修复**：

```bash
# 1. 加入 devDependencies
bun add -d @biomejs/biome

# 2. 清理临时文件（确认都是空文件或安全后才删）
ls biome-*.txt  # 检查内容
rm biome-*.txt

# 3. 在 .gitignore 增加（防止再产生）
echo "biome-*.txt" >> .gitignore

# 4. 提交
git add package.json bun.lockb .gitignore
git commit -m "build: add @biomejs/biome to devDependencies and clean up temp files"
```

**风险**：

- `rm biome-*.txt` 一定要先 `ls` 看内容；如果是非空文件，单独 commit
- `bun.lockb` 改后必须配合 `bun install --frozen-lockfile` 验证 CI 仍可装

**验证**：

```bash
# 新开发者应能跑
bun install
bunx biome --version  # 应显示版本号

# CI 跑法
bunx biome ci .
```

**估时**：5 分钟。

## 6. P2 — 工程细节

### 6.1 (F10) vitest vs bun test 双 runner

**现状**：

- `package.json` scripts 写 `test: vitest`
- `.github/workflows/ci.yml` 跑 `bun test`

**风险**：

- `bun test` 兼容 vitest 大部分 API，但**不兼容** `vi.mock` 的所有特性、`expect.assertions`、某些快照行为
- 本地 `vitest --watch` 看到的行为可能跟 CI `bun test` 不一致

**选项**：

A. **统一为 bun test**（推荐）：项目以 bun 为运行时，bun test 足够

```diff
- "test": "vitest"
+ "test": "bun test"
```

B. **统一为 vitest**（更成熟生态）：CI 装 `bun` + `vitest`

```diff
# ci.yml
- run: bun test
+ run: bunx vitest run
```

C. **保留双 runner**（不推荐）：增加文档说明 `bunfig.toml` 应配置

**估时**：30 分钟（选项 A）。

### 6.2 (F11) `.editorconfig` 与实际文件 CRLF/LF 冲突

**现状**：

- `.editorconfig` 写 `end_of_line = lf`
- 实际大量源文件是 CRLF（Windows 编辑器残留）

**选项**：

A. **改为 CRLF**（如果团队都是 Windows）

```ini
end_of_line = crlf
```

B. **全量转 LF**（推荐，跨平台友好）

```bash
# 在仓库根跑
find . -type f \( -name "*.ts" -o -name "*.tsx" -o -name "*.md" -o -name "*.json" \) -exec dos2unix {} \;
# 或 PowerShell：
Get-ChildItem -Recurse -Include *.ts,*.tsx,*.md,*.json | ForEach-Object {
  (Get-Content $_.FullName -Raw) -replace "`r`n", "`n" | Set-Content $_.FullName -NoNewline
}
```

C. **加 `.gitattributes`**：

```gitattributes
* text=auto eol=lf
*.bat text eol=crlf
*.cmd text eol=crlf
```

**估时**：1 小时（含验证）。

## 11. 勘误与教训（新增）

### 11.1 勘误记录

- **ERR-1 / ERR-2**（见文档首部）：本审计初版误判 CHANGELOG.md / README.md 为 GBK，且误判 CHANGELOG `[Unreleased]` 段为空。已用 Node `TextDecoder('utf8', {fatal:true})` 严格模式验证全仓 221 个文本文件，**全部合法 UTF-8**。CHANGELOG 实际有 30+ 条具体变更。

### 11.2 教训：编码检测的正确做法

**错误做法**：

```powershell
Get-Content README.md   # PowerShell 默认按系统 ANSI (CP936/GBK) 解码 UTF-8 字节 → 假乱码
```

**正确做法**：

```bash
# 方案 1: 强制 UTF-8
Get-Content README.md -Encoding UTF8

# 方案 2: Node 严格模式 (推荐, 可编程化)
node -e "const fs=require('fs');const b=fs.readFileSync('README.md');try{new TextDecoder('utf8',{fatal:true}).decode(b);console.log('UTF-8 OK');}catch(e){console.log('NOT UTF-8');}"

# 方案 3: 字节级判断
node -e "const fs=require('fs');const b=fs.readFileSync('README.md');console.log('GBK字节范围(0x81-0xFE):',b.filter(x=>x>=0x81&&x<=0xfe).length);"
```

**全仓扫描命令**（已验证 0 失败）：

```bash
node -e "const fs=require('fs'),path=require('path');function walk(d,o=[]){for(const e of fs.readdirSync(d,{withFileTypes:true})){const p=path.join(d,e.name);if(e.isDirectory()){if(['node_modules','.git','dist','build','coverage','.licode'].includes(e.name))continue;walk(p,o);}else o.push(p);}return o;}const exts=['.md','.ts','.tsx','.json','.yml','.yaml'];const bad=walk('.').filter(f=>exts.includes(path.extname(f).toLowerCase())).filter(f=>{try{new TextDecoder('utf8',{fatal:true}).decode(fs.readFileSync(f));return false;}catch{return true;}});console.log('非 UTF-8 文件数:',bad.length);"
```

### 11.3 教训：审计类任务必须双重验证

- **可量化的指标**（文件数、行数、any 数） → 用工具直接量
- **编码 / 二进制字段** → 用 Node `TextDecoder` 或 hex dump，不要靠编辑器/PowerShell 默认显示
- **内容断言** → 完整 dump 出来看，不要靠 `Select-String -First N` 截断
- **本审计的 2 处误判**正是因为用了 PowerShell 默认 ANSI 解码又没二次验证

// Node 严格 UTF-8 检测
const fs = require('fs');
const path = require('path');

function walk(d, out = []) {
  for (const e of fs.readdirSync(d, { withFileTypes: true })) {
    const p = path.join(d, e.name);
    if (e.isDirectory()) {
      if (['node_modules', '.git', 'dist', 'build', 'coverage', '.licode'].includes(e.name)) continue;
      walk(p, out);
    } else {
      out.push(p);
    }
  }
  return out;
}
